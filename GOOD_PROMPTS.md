# GOOD PROMPTS

This files contains some good prompts I find useful for this project.

## Simlpification

this is delicate: I like my code lean, you on the opposite like to add as much features as possible. I would like you to parse all the code and search for things that should be simplified or removed. Search everywhere: code and tests. Don't be too aggressive though, the idea is to check for overengineered parts, never used features and absurd tests. The problem is that reviewing code costs time and effort and I don't want to waste on both. Don't change anything just report.
